# Админка УЗМ

Payload CMS хранит разделы, товары, медиа, заявки и учётные записи редакторов. Сейчас это локальная заготовка для будущего серверного размещения. Публичный сайт читает свой реестр в `../src/data`; изменения в админке ещё не появляются на нём автоматически.

## Запуск

1. Скопируйте `.env.example` в `.env` и задайте длинный `PAYLOAD_SECRET`.
2. Установите зависимости: `npm install`.
3. Загрузите каталог: `npm run seed:catalog`.
4. Запустите админку: `npm run dev`.

При первом открытии `/admin` создайте учётную запись администратора. Скрипт загрузки создаёт разделы и товары как черновики. Повторный запуск добавляет новые позиции и не удаляет отредактированные записи.

## Перед серверным запуском

Нужны отдельный адрес админки, постоянное хранилище базы и файлов, HTTPS, резервные копии, почтовый сервис для уведомлений, правила доступа к заявкам и серверный обмен с 1С и CRM. Параметры интеграций заказчик ещё не передал. Не публикуйте админку с примером секрета из `.env.example`.
