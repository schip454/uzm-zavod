# УЗМ Завод — прототип нового сайта

Кликабельная первая версия сайта для показа заказчику 12 октября 2026 года. Разработка ведётся на Next.js и TypeScript. Название компании в интерфейсе: **«Уральский завод металлоконструкций»**, как подтвердил заказчик.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Next.js в терминале (обычно `http://localhost:3000`). Проверка сборки: `npm run build`. Проверка типов: `npm run typecheck`.

## Что уже можно показать

- Главная с новым визуальным направлением на основе тёмного и оранжевого цветов прежнего сайта.
- Каталог: 19 групп, переключение направлений и поиск по названию.
- Страница опор освещения: фильтр по назначению, поиск по серии и 14 первых карточек.
- Карточка модели с переходом к форме. Выбранное изделие подставляется автоматически.
- Адаптивная версия и мобильное меню.
- Форма с полями из ТЗ и проверкой заполнения. **Отправка отключена:** после проверки форма прямо сообщает, что данные никуда не переданы.

## Материалы и проверка

Логотип и фотографии в `public/images` взяты с действующего сайта [uzmzavod.ru](https://uzmzavod.ru/). Названия групп и серий для первого набора взяты из открытого [каталога «Декарта»](https://dekart.tech/shop/). Скрипт `scripts/extract-dekart-catalog.py` собрал 199 уникальных ссылок в `research/dekart-url-inventory.csv`; сырой HTML в Git не включён.

Реестр и демо-карточки не подтверждают, что УЗМ производит каждую серию. До публичного запуска нужно сверить ассортимент, характеристики, чертежи, фотографии и права на размещение материалов. Действующие телефон и почта в прототипе взяты со старого сайта; контакты по направлениям заказчик уточняет отдельно.
